## 🎯 Questions to Anticipate

### **Q: "How do you ensure the AI doesn't fail?"**
**A:** "We have a two-tier system: primary OpenAI API with 85% confidence, and fallback rule-based categorization with 65% confidence. The service automatically switches if the API is unavailable."

### **Q: "Can users correct AI categorizations?"**
**A:** "Absolutely! We have a recategorization endpoint that can be triggered by users, and the AI learns from corrections over time." *(Even if not fully implemented, show the architecture supports it)*

### **Q: "How does this integrate with the main wallet?"**
**A:** "The microservice imports transaction data through JSON files, but it's designed to also support REST API calls, Kafka events, or database connections - whatever the main wallet uses."

### **Q: "What about security?"**
**A:** "For production, we'd move API keys to environment variables, add authentication, rate limiting, and HTTPS. The architecture is ready for these additions."

### **Q: "How scalable is this?"**
**A:** "It's containerized, has health endpoints for Kubernetes, uses caching for performance, and follows stateless microservices principles. It can scale horizontally."
